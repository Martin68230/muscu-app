# Base de connaissances : source de vérité du contenu sport, santé et nutrition
Aucune valeur n'entre dans le code sans une entrée ici avec source et statut validé.
Format d'une entrée : règle/valeur ; public concerné ; source (URL) ; niveau de preuve ; vérifié le ; limites ; statut (OK / PROVISOIRE / NON SOURCÉ) ; contrôlé par `relecteur` le.
Fichiers :
- program-logic.md : bases ACSM 2026, ordre, répartition, volume, charges, supersets, cardio, rotation, progression, fonctionnel.
- load-calibration.md : étalonnage, réserve, double progression.
- goal-resolver.md : fusion des objectifs.
- schedule-adaptation.md : séances manquées.
- rest-and-volume-rules.md : repos et volume (en cours).
- sports.md : familles et prévention.
- equipment-taxonomy.md : tags de matériel, choix de variante, trous de couverture.
- exercise-catalog.md : structure, licences, plan de vérification ; exercise-library-draft.csv (brouillon) ; library-stats.json (statistiques) ; exercises-notes.md (notes).
- nutrition-rules.md : besoins, protéines, perte/prise, compléments, Ciqual, plan de repas.
- sources.md : toutes les sources et ce qui a réellement été lu.
