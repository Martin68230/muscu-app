# Idées de fonctionnalités
Décisions du 21/10/2026 : pas de messagerie (app simple) ; plan de repas généré + compléments ajoutés par l'utilisateur ; sports : foot, danse, volley, raquettes. Les idées retenues sont placées dans docs/plan-de-construction.md.
**Recommandées** : replanification des séances manquées ; échauffement/retour au calme générés ; détection de progression (proposer d'augmenter) ; mode pressé 20 min et mode sans matériel ; journal enrichi (RPE, énergie, sommeil, douleur par zone) ; poids lissé (moyenne mobile) et mensurations ; records et résumé hebdo ; export/import JSON ; hors-ligne pendant la séance.
**Social** : fil d'amis, séries de jours, défis hebdo, encouragements, chacun choisit ce qu'il partage (poids caché par défaut).
**Nutrition** : menus selon objectif, liste de courses, substitutions, favoris, objectifs protéines/eau ; table Ciqual ; code-barres via Open Food Facts (licence à vérifier) plus tard.
**Santé** : profil blessures, rappel « pas un avis médical », alerte de fatigue accumulée, semaine de décharge proposée ; pas d'accès à Apple Santé en PWA : saisie manuelle.
**Confort** : minuteur visible, vibration/son, écran allumé, mode sombre, lecture vocale des consignes (synthèse vocale du navigateur), filtres de bibliothèque (matériel, muscle, niveau, maison), favoris.
**IA (interrupteur global)** : prompt + import JSON, mini-chatbot par exercice, relecture critique d'un programme (toujours bornée par les règles du code).
**À éviter** : photos de progression en ligne, classements publics, comparaisons de poids, récompenses qui poussent au sur-entraînement ou aux régimes extrêmes.
