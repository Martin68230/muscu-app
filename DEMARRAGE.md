# Démarrer dans Claude Code
1. Dézippe ce dossier sur ton PC (ex. Documents/muscu-app).
2. Ouvre l'application Claude, onglet **Code**, et choisis ce dossier.
3. Choisis le modèle Opus pour cette première session (modèle de données).
4. Colle ce message :

> Lis CLAUDE.md, docs/plan-de-construction.md, docs/cahier-des-charges.md, docs/architecture.md et knowledge/README.md. Résume-moi en 10 lignes ce que tu as compris et pose-moi tes questions bloquantes s'il y en a. Ensuite : (1) lance la phase 0 (fondations + modèle de données local prêt pour la synchronisation), avec tests ; (2) en parallèle, fais préparer par l'agent `coach` le lot pilote d'environ 30 mouvements (phase 1), complété par `kine` et contrôlé par `relecteur`, puis montre-moi 5 fiches pour que je valide le format avant de continuer. L'app est faite pour être utilisée sur iPhone (règles d'affichage, section D de CLAUDE.md) : montre-moi chaque écran en format téléphone. Avance par petites étapes et dis-moi ce que je dois vérifier sur mon iPhone.

5. Avant d'inviter tes amis (phase 6) : compte GitHub, compte Supabase (région UE) et un service d'email gratuit. Claude Code te guidera.
