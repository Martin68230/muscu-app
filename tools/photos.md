Pourquoi le recadrage (décision de l'utilisateur, 21/10/2026) : les originaux montrent le mur « Boise CrossFit » de la salle (logo d'un tiers). Le recadrage enlève ce logo sans couper le geste (tête, bras, mains, pieds et appui restent visibles). Restes connus : l'appui est une box en bois (pas un banc ni une chaise : à ne montrer que pour les échelons chaise et marche, voir la fiche `pompe-inclinee`) ; dans `-1`, la box est coupée sur son bord gauche ; une petite bannière sombre illisible reste en haut de `-1`. Décision coach 22/10/2026 : `-0` affichable (échelon pompe-chaise, mention box) ; `-1` non affiché (bannière résiduelle, recadrage impossible sans couper la tête).

Convention de nommage : `<dossier free-exercise-db>-<numéro>.webp`. Largeur 600 px, qualité 70, environ 20 Ko par image. Le script `npm run check:fiches` avertit (sans bloquer) si une image marquée « oui » n'a pas son fichier WebP ici.
